    Slide 08

    Errors Are Normal! 🐛

    A compiler error is not failure — it is feedback

    ❌
    Syntax Error
    Breaking grammar rules. Like writing a sentence without punctuation.
    // Missing semicolon
printf("Hello")  // ERROR!
    ⚠️
    Logic Error
    Code runs but gives wrong answer. The hardest to find!
    // Wanted average, wrong formula
avg = a + b / 2;  // BUG!
// Should be: (a + b) / 2
    💥
    Runtime Error
    Crashes during execution. Like dividing by zero.
    int x = 10 / 0;  // CRASH!
// Division by zero
    💡 Remember: Every programmer — even experts — encounters errors daily. The skill is not avoiding errors but reading error messages and fixing them. Debugging is problem solving!

    Declaring & Initializing Variables

    variables.c
    #include <stdio.h>

int main()
{
    // Declaration (create the box)
    int age;
    float salary;
    char grade;

    // Initialization (put value in box)
    age = 21;
    salary = 55000.50;
    grade = 'A';

    // Declaration + Initialization
    int year = 2024;
    double pi = 3.14159;

    // Display values
    printf("Age: %d\n", age);
    printf("Salary: %.2f\n", salary);
    printf("Grade: %c\n", grade);

    3. You can do both in one line: int x = 10;
    4. printf uses format specifiers to display values

    ✓ Must start with letter or underscore
    ✓ Can contain letters, digits, underscores

    ✗ Cannot use reserved words: int, return

    Assignment: = is NOT "equals"!

    This is one of the most important beginner concepts

    = means "store this value", NOT "is equal to"
    assignment.c
    int x = 10;   // Store 10 in x
x = 20;       // Now x holds 20 (10 is gone!)
x = x + 5;   // x = 20 + 5 = 25
    StepStatementx
    1int x = 1010
    2x = 2020
    3x = x + 525
    🌍 Analogy
    x = 20 means "erase what's in the box labeled x, and write 20 instead." The old value is overwritten.
    🚫 Common Confusion:
    = → Assignment (store a value)
    == → Comparison (check if equal)

    x = 5 stores 5 in x
    x == 5 checks if x equals 5

    ⚠️ Integer Division

    This catches EVERY beginner — pay close attention!

    When you divide two integers, C throws away the decimal part!
    printf("%d\n", 5 / 2);     // 2  (not 2.5!)
printf("%d\n", 7 / 3);     // 2  (not 2.33!)
printf("%d\n", 1 / 2);     // 0  (not 0.5!)
    🚫 The Fix: Use float or 5.0 / 2.0
    printf("%f\n", 5.0 / 2.0);  // 2.500000 ✓
printf("%f\n", (float)5 / 2); // 2.500000 ✓
    🌍 Analogy
    Dividing 5 cookies among 2 people:
    Integer: Each gets 2 cookies, 1 is left over → 5/2=2, 5%2=1
    Float: Each gets 2.5 cookies → 5.0/2.0=2.5
    🔢 Modulus = Remainder
    17 % 5 = 2 because 17 = 5 × 3 + 2

    Real use: Check if a number is even: n % 2 == 0
    Part 2 · Slide 27

    Increment & Decrement

    Pre vs Post
    ++a → increment FIRST, then use the value
    a++ → use the value FIRST, then increment
    #include <stdio.h>

int main()
{
    int a = 5;
    printf("%d\n", a++);  // prints 5, then a=6
    printf("%d\n", a);    // prints 6

    int b = 5;
    printf("%d\n", ++b);  // b=6 first, prints 6
    printf("%d\n", b);    // prints 6

    return 0;
}
    ▶ Output
    5 6 6 6
    ExpressionBeforePrintedAfter
    a++556
    ++b566
    a--665
    --b655
    🌍 Simple Rule
    Post (a++): "Use me NOW, change me LATER"
    Pre (++a): "Change me FIRST, then use me"
    💡 When used alone (like a++; on its own line), pre and post are identical. The difference only matters inside expressions.

    Program: Simple Interest Calculator

    simple_interest.c
    #include <stdio.h>

int main()
{
    float principal, rate, time;
    float si, amount;

    // Get input
    printf("Enter Principal: ");
    scanf("%f", &principal);

    printf("Enter Rate (%%): ");
    scanf("%f", &rate);

}

    Part 3 · Slide 34

    else-if Ladder — Grade Calculator

    grades.c
    #include <stdio.h>

int main()
{
    int marks;

    printf("Enter marks (0-100): ");
    scanf("%d", &marks);

    if (marks >= 90)
        printf("Grade: A+ (Outstanding!)\n");
    else if (marks >= 80)
        printf("Grade: A (Excellent)\n");
    else if (marks >= 70)
        printf("Grade: B (Good)\n");
    else if (marks >= 60)
        printf("Grade: C (Average)\n");
    else if (marks >= 50)
        printf("Grade: D (Below Average)\n");
    else
        printf("Grade: F (Fail)\n");

    return 0;
}
    ▶ Output (marks = 78)
    Enter marks (0-100): 78 Grade: B (Good)
    🔍 How It Works
    Conditions are checked top to bottom:
    78 >= 90? No ↓
    78 >= 80? No ↓
    78 >= 70? YES → "Grade: B" ✓
    Rest is skipped
    📌 Order matters! If you put marks >= 50 first, everyone scoring 50+ would get Grade D, even those with 95!

    Program: Prime Number Check

    📋 What is Prime?
    A number > 1 that has exactly two factors: 1 and itself.
    Examples: 2, 3, 5, 7, 11, 13, 17, 19...
    Not prime: 4 (1,2,4), 6 (1,2,3,6), 9 (1,3,9)
    prime.c
    #include <stdio.h>

int main()
{
    int n, isPrime = 1;

    printf("Enter a number: ");
    scanf("%d", &n);

    if (n <= 1)
        isPrime = 0;

    for (int i = 2; i * i <= n; i++)
    {
        if (n % i == 0)
        {
            isPrime = 0;
            break;
        }
    }

    if (isPrime)
        printf("%d is Prime\n", n);
    else
        printf("%d is Not Prime\n", n);

    return 0;
}
    ▶ Output
    Enter a number: 29 29 is Prime
    🔍 Algorithm
    For n=29, check divisibility by 2,3,4,5 (√29≈5.4):
    29 % 2 = 1 (not divisible) ↓
    29 % 3 = 2 (not divisible) ↓
    29 % 4 = 1 (not divisible) ↓
    29 % 5 = 4 (not divisible) ↓
    No divisor found → Prime!
    💡 Optimization: We only check up to √n. If a number has a factor > √n, it must also have one < √n.

    In C, functions receive COPIES of arguments — the originals are safe

    printf("Inside function: x = %d\n", x);
}

    What is Recursion?

    A function that calls itself
    🔑 Two Rules — ALWAYS
    1. Base Case — When to STOP (prevents infinite recursion)

    2. Recursive Case — The function calls itself with a smaller problem 
    void countdown(int n)
{
    if (n == 0)        // Base case
        return;

    printf("%d\n", n);
    countdown(n - 1);  // Recursive call
}
    📊 Factorial: n! = n × (n-1)!
    long factorial(int n)
{
    if (n <= 1)
        return 1;
    return n * factorial(n - 1);
}
    📊 Call Stack for factorial(4)
    factorial(4) → 4 × factorial(3)
      factorial(3) → 3 × factorial(2)
        factorial(2) → 2 × factorial(1)
          factorial(1) → 1
        = 2 × 1 = 2
      = 3 × 2 = 6
    = 4 × 6 = 24

    Linear Search

    Check each element one by one until found

    linear_search.c
    #include <stdio.h>

int linearSearch(int arr[], int n, int key)
{
    for (int i = 0; i < n; i++)
    {
        if (arr[i] == key)
            return i;  // Found at index i
    }
    return -1;  // Not found
}

int main()
{
    int arr[] = {10, 25, 40, 56, 73, 88};
    int n = 6, key;

    printf("Enter number to find: ");
    scanf("%d", &key);

    int pos = linearSearch(arr, n, key);

    if (pos != -1)
        printf("Found at index %d\n", pos);
    else
        printf("Not found!\n");

    return 0;
}

    Binary Search

    Divide and conquer — requires a SORTED array

    binary_search.c
    #include <stdio.h>

int binarySearch(int arr[], int n, int key)
{
    int low = 0, high = n - 1;

    while (low <= high)
    {
        int mid = (low + high) / 2;

        if (arr[mid] == key)
            return mid;
        else if (key < arr[mid])
            high = mid - 1;
        else
            low = mid + 1;
    }
    return -1;
}

int main()
{
    int arr[] = {10, 20, 30, 40, 50, 60, 70, 80};
    int n = 8;

    int pos = binarySearch(arr, n, 50);
    if (pos != -1)
        printf("Found at index %d\n", pos);
    else
        printf("Not found\n");

    return 0;
}
    ▶ Output
    Found at index 4
    🔍 Trace: Finding 50
    [10 20 30 40 50 60 70 80] mid=40, 50>40 → go right
    [60 70 80]   mid=60, 50<60 → go left
    [50]         mid=50 ✓ FOUND!

    Bubble Sort

    Repeatedly swap adjacent elements if they're in wrong order

    bubble_sort.c
    #include <stdio.h>

void bubbleSort(int arr[], int n)
{
    for (int i = 0; i < n - 1; i++)
    {
        for (int j = 0; j < n - i - 1; j++)
        {
            if (arr[j] > arr[j + 1])
            {
                // Swap
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}

int main()
{
    int arr[] = {64, 34, 25, 12, 22, 11, 90};
    int n = 7;

    bubbleSort(arr, n);

    printf("Sorted: ");
    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);
    printf("\n");

    return 0;
}
    ▶ Output
    Sorted: 11 12 22 25 34 64 90
    🔍 Visual Trace (first pass)
    [64 34] 25 12 → swap → [34 64 25] 12 → swap
    34 [25 64] 12 → [25 34 64 12] → swap
    After pass 1: largest (64) "bubbles" to end!
    🌍 Analogy
    Like bubbles rising in water — the largest element "bubbles up" to the top in each pass.

    Selection Sort

    Find the minimum element and put it in the correct position

    selection_sort.c
    #include <stdio.h>

void selectionSort(int arr[], int n)
{
    for (int i = 0; i < n - 1; i++)
    {
        int minIdx = i;

        // Find minimum in remaining
        for (int j = i + 1; j < n; j++)
        {
            if (arr[j] < arr[minIdx])
                minIdx = j;
        }

        // Swap minimum with position i
        int temp = arr[i];
        arr[i] = arr[minIdx];
        arr[minIdx] = temp;
    }
}

int main()
{
    int arr[] = {29, 10, 14, 37, 13};
    int n = 5;

    selectionSort(arr, n);

    printf("Sorted: ");
    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);

    return 0;
}
    ▶ Output
    Sorted: 10 13 14 29 37
    🔍 Visual Trace
    [29 10 14 37 13] → min=10 → swap with pos 0
    [10 | 29 14 37 13] → min=13 → swap with pos 1
    [10 13 | 14 37 29] → min=14 → already there
    [10 13 14 | 37 29] → min=29 → swap with pos 3
    [10 13 14 29 37] → Done!

    Insertion Sort

    Like sorting playing cards in your hand — one at a time

    insertion_sort.c
    #include <stdio.h>

void insertionSort(int arr[], int n)
{
    for (int i = 1; i < n; i++)
    {
        int key = arr[i];
        int j = i - 1;

        // Shift elements greater than key
        while (j >= 0 && arr[j] > key)
        {
            arr[j + 1] = arr[j];
            j--;
        }

        arr[j + 1] = key;
    }
}

int main()
{
    int arr[] = {12, 11, 13, 5, 6};
    int n = 5;

    insertionSort(arr, n);

    printf("Sorted: ");
    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);

    return 0;
}
    ▶ Output
    Sorted: 5 6 11 12 13
    🃏 Playing Cards Analogy
    Pick up cards one at a time. Each new card is inserted into its correct position among the cards you're already holding.
