01 · recursion

THE NATURE OF RECURSION

  • Recursion — a function that calls itself, directly or indirectly. The function solves a smaller version of the same problem, then combines results.
  • Base case — the simplest input that can be answered without recursion. It stops the chain of calls. Without it: infinite recursion → stack overflow.
  • Recursive step — reduces the problem toward the base case and calls itself. Each call must make progress.
  • Divide and conquer — break a big problem into smaller identical sub-problems, solve each recursively, combine.
countdown.c — simplest recursion
void countdown(int n)
{
    if (n <= 0) {              ← BASE CASE
        printf("Go!\n");
        return;
    }
    printf("%d...\n", n);
    countdown(n - 1);         ← RECURSIVE CALL
}

/* countdown(3) produces:
   3...
   2...
   1...
   Go!

   3 calls countdown(2)
   2 calls countdown(1)
   1 calls countdown(0) → base case */
02 · recursion

TRACING — STACK FRAMES

factorial — stack trace
int factorial(int n)
{
    if (n <= 1) return 1;          ← base
    return n * factorial(n - 1);   ← recurse
}

/* call factorial(4) — stack grows DOWN */

┌─────────────────────────┐
│ factorial(4)              │ n=4
│   return 4 * factorial(3)│
├─────────────────────────┤
│ factorial(3)              │ n=3
│   return 3 * factorial(2)│
├─────────────────────────┤
│ factorial(2)              │ n=2
│   return 2 * factorial(1)│
├─────────────────────────┤
│ factorial(1)              │ n=1
│   return 1  ← base case   │
└─────────────────────────┘

/* unwind: 1 → 2*1=2 → 3*2=6 → 4*6=24 */
STACK FRAME
Each recursive call creates a new stack frame with its own copy of n. The frames accumulate until the base case.
WINDING
Calls go deeper: 4→3→2→1. Each waits for the result of the next. The base case returns first.
UNWINDING
Results propagate back: 1→2→6→24. Each frame multiplies its n by the returned value and sends it up.
⚠ STACK OVERFLOW
Too-deep recursion exhausts stack memory. factorial(100000) would crash. Use iteration for very deep computations.
03 · recursion

RECURSIVE MATH FUNCTIONS

recursive_math.c
/* FACTORIAL: n! = n × (n-1)! */
int fact(int n) {
    if (n <= 1) return 1;
    return n * fact(n - 1);
}

/* POWER: x^n = x × x^(n-1) */
double power(double x, int n) {
    if (n == 0) return 1.0;
    return x * power(x, n - 1);
}

/* FIBONACCI: f(n) = f(n-1) + f(n-2) */
int fib(int n) {
    if (n <= 0) return 0;
    if (n == 1) return 1;
    return fib(n-1) + fib(n-2);
}

/* GCD: Euclid's algorithm */
int gcd(int a, int b) {
    if (b == 0) return a;
    return gcd(b, a % b);
}
MATHEMATICAL DEFINITION
Many math functions are defined recursively. The code mirrors the definition directly — elegant and provably correct.
⚠ FIBONACCI IS SLOW
Naive fib(n) has O(2ⁿ) time — it recomputes the same values exponentially. fib(40) takes seconds. Use iteration or memoization for large n.
GCD — ELEGANT
Euclid's algorithm: gcd(a,b) = gcd(b, a%b). Base: b==0 → return a. Runs in O(log n) steps — recursion done right.
04 · recursion

RECURSION WITH ARRAYS

recursive_array.c
/* SUM of array elements */
int array_sum(int arr[], int n)
{
    if (n <= 0) return 0;       ← base
    return arr[n-1] + array_sum(arr, n-1);
}
/* sum({3,5,2}, 3)
   = 2 + sum({3,5,2}, 2)
   = 2 + 5 + sum({3,5,2}, 1)
   = 2 + 5 + 3 + sum({3,5,2}, 0)
   = 2 + 5 + 3 + 0 = 10              */

/* FIND MAX in array */
int array_max(int arr[], int n)
{
    if (n == 1) return arr[0];
    int rest_max = array_max(arr, n-1);
    return (arr[n-1] > rest_max)
           ? arr[n-1] : rest_max;
}
THE PATTERN
Process the last element, then recursively process the rest (n-1 elements). Base case: empty array or single element.
SHRINKING RANGE
Each call decrements n. The array itself is unchanged — only the "window" shrinks. The pointer stays the same.
RECURSION vs LOOP
A loop is simpler and faster for array traversal. Recursion is elegant but has function-call overhead per element. Choose based on clarity vs. performance.
05 · recursion

RECURSION WITH STRINGS

recursive_string.c
/* recursive string length */
int my_strlen(char *s)
{
    if (*s == '\0') return 0;   ← base
    return 1 + my_strlen(s + 1); ← next char
}

/* reverse print */
void print_reverse(char *s)
{
    if (*s == '\0') return;
    print_reverse(s + 1);   ← recurse first
    printf("%c", *s);       ← print on unwind
}
/* print_reverse("CAT") → TAC */

/* check palindrome */
int is_palindrome(char *s, int lo, int hi)
{
    if (lo >= hi) return 1;
    if (s[lo] != s[hi]) return 0;
    return is_palindrome(s, lo+1, hi-1);
}
BASE CASE: \0
The null terminator is the natural base case for string recursion. When *s == '\0', the string is empty — stop.
POINTER ARITHMETIC
s + 1 moves to the next character. Each recursive call processes a shorter string — one char closer to \0.
ORDER MATTERS
print_reverse: recurse before printing → prints in reverse order. Recurse after printing → prints forwards. The placement changes behavior.
PALINDROME TRICK
Compare first and last chars. If equal, recurse on the substring s[lo+1..hi-1]. Base: indices cross → it's a palindrome.
01 · structures

USER-DEFINED STRUCTURE TYPES

struct.c
/* define a structure type */
typedef struct {
    char   name[50];
    int    id;
    double gpa;
} student_t;

int main(void)
{
    /* declare and initialize */
    student_t s1 = {"Alice", 1001, 3.85};

    /* access with dot operator */
    printf("Name: %s\n", s1.name);
    printf("ID:   %d\n", s1.id);
    printf("GPA:  %.2f\n", s1.gpa);

    /* modify a member */
    s1.gpa = 3.90;

    /* copy entire struct */
    student_t s2 = s1;  ← copies all members

    return (0);
}
struct
Groups different types under one name. A student has a name (char[]), an id (int), and a gpa (double).
typedef
Creates a type alias: student_t instead of struct student. Shorter, cleaner code.
Dot operator (.)
s1.name accesses the name member. Each member is like an independent variable.
Assignment (=)
Unlike arrays, structs CAN be assigned with =. Every member is copied. This is a deep copy for scalar members.
⚠ NO == FOR STRUCTS
You cannot compare structs with ==. Compare member by member, or write a comparison function.
02 · structures

STRUCTURES AS PARAMETERS

struct_params.c
/* INPUT parameter — pass by value (copy) */
void print_student(student_t s)
{
    printf("%s (ID:%d) GPA:%.2f\n",
           s.name, s.id, s.gpa);
}

/* OUTPUT parameter — pass by pointer */
void read_student(student_t *sp)
{
    printf("Name> ");
    scanf("%s", sp->name);  ← arrow!
    printf("ID>   ");
    scanf("%d", &sp->id);
    printf("GPA>  ");
    scanf("%lf", &sp->gpa);
}

/* usage */
student_t s;
read_student(&s);      ← fills s
print_student(s);      ← reads s
ARROW OPERATOR (→)
When you have a pointer to a struct, use sp->member instead of (*sp).member. Same thing, cleaner syntax.
BY VALUE = COPY
print_student(s) copies the entire struct onto the stack. Safe (original unchanged) but expensive for large structs.
BY POINTER = MODIFY
read_student(&s) passes the address. The function fills the caller's struct through the pointer. Efficient and necessary for output.
⚠ EFFICIENCY TIP
For large structs used as input only, pass a const pointer: void print(const student_t *sp) — no copy, no accidental modification.
03 · structures

FUNCTIONS RETURNING STRUCTURES

struct_return.c
typedef struct {
    double x, y;
} point_t;

/* return a struct by value */
point_t make_point(double x, double y)
{
    point_t p;
    p.x = x;
    p.y = y;
    return p;   ← copy returned
}

/* compute midpoint */
point_t midpoint(point_t a, point_t b)
{
    return make_point(
        (a.x + b.x) / 2.0,
        (a.y + b.y) / 2.0
    );
}

/* usage */
point_t p1 = make_point(1.0, 2.0);
point_t p2 = make_point(5.0, 8.0);
point_t m  = midpoint(p1, p2);
/* m.x = 3.0, m.y = 5.0 */
CONSTRUCTOR PATTERN
make_point(x, y) acts like a constructor — creates and returns a struct. Clean, readable, reusable.
COMPOSABILITY
midpoint takes two points, returns a point. Functions that accept and return structs compose naturally — building complex logic from simple pieces.
⚠ RETURN = COPY
Returning a struct copies it. For small structs (point, complex number) this is fine. For large structs, consider output pointers instead.
04 · structures

NESTED STRUCTURES

nested.c
typedef struct {
    int day, month, year;
} date_t;

typedef struct {
    char    name[50];
    int     id;
    date_t  birth;        ← struct inside struct
    date_t  hire;
} employee_t;

employee_t e = {
    "Alice", 1001,
    {15, 3, 1990},        ← birth
    {1,  9, 2020}         ← hire
};

/* access nested members: chain dots */
printf("Born: %d/%d/%d\n",
       e.birth.day,
       e.birth.month,
       e.birth.year);
COMPOSITION
Structures can contain other structures as members. employee_t contains two date_t members — natural data modeling.
CHAINED DOTS
e.birth.day — first select the birth member (a date_t), then select day within it. Reads left to right.
ARRAYS OF STRUCTS
employee_t staff[100]; — an array where each element is a complete employee record. staff[i].name accesses the i-th employee's name.
05 · unions

UNION TYPES

union.c
/* union: ALL members SHARE the same memory */
typedef union {
    int    i;      ← 4 bytes
    double d;      ← 8 bytes
    char   c;      ← 1 byte
} value_t;
/* sizeof(value_t) = 8 (size of largest) */

value_t v;
v.i = 42;             ← store as int
printf("%d\n", v.i);   → 42 ✓

v.d = 3.14;            ← OVERWRITES i!
printf("%.2f\n", v.d); → 3.14 ✓
printf("%d\n", v.i);   → garbage!

/* tagged union — track which is active */
typedef struct {
    int  tag;    /* 0=int, 1=double, 2=char */
    value_t val;
} tagged_t;
SHARED MEMORY
All union members overlap in memory. Only one member is valid at a time. Size = size of the largest member.
struct vs union
struct: members are side by side (all active). union: members are stacked on top (one active). Struct size = sum; union size = max.
TAGGED UNION
Wrap the union in a struct with a tag field that records which member is currently valid. The safe way to use unions.
⚠ READING WRONG MEMBER
Writing v.d = 3.14 then reading v.i gives garbage — the bit pattern of a double interpreted as an int. Always track the active member.
06 · comparison

STRUCT vs UNION

Feature struct union
Members all coexist, separate memory share same memory location
Active all members at once only ONE at a time
Size sum of all members (+padding) size of largest member
Use case group related data save memory, variant types
Assignment copies all members copies the entire block
Safety always safe to read any member must track active member
size_demo.c
typedef struct {
    int    i;    /* 4 */
    double d;    /* 8 */
    char   c;    /* 1 */
} s_type;
/* sizeof(s_type) ≈ 16 (with padding) */

typedef union {
    int    i;
    double d;
    char   c;
} u_type;
/* sizeof(u_type) = 8  (largest member) */

printf("struct: %lu bytes\n",
       sizeof(s_type));    → 16
printf("union:  %lu bytes\n",
       sizeof(u_type));    → 8
